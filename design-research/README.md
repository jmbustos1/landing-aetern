# Design Research

Exploración de estética previa a AETERN. **Esto es investigación, no el producto**
(el producto vive en [`../site`](../site)).

`skills/` contiene **12 "skills" de diseño** destiladas de repos reales de GitHub. Cada
una captura un lenguaje visual (paleta con hex exactos, tipografía, layout, componentes,
motion, anatomía de secciones) como una spec reutilizable, con un bloque "prompt listo
para usar" para recrear ese look desde cero.

La que se eligió y construyó para AETERN fue **`house-blend`** — ver
[`../docs/DISENO-AETERN.md`](../docs/DISENO-AETERN.md).

## Las 12 skills

**☕ Café / asiático claro**
`nordic-coffee` · `japandi` · `yohaku` · `wabi-sabi` · `fresh` · `odyssey`

**🌘 Dark / tech sobrio**
`dark-wabisabi` · `sumi-e-ink` · `tui-terminal` · `neo-tokyo-tiling` · `sober-dark-tech` · **`house-blend`** ⭐

> Nota: los repos originales de referencia y los previews de demo (fresh/japandi/odyssey)
> no se versionan — eran scratch de exploración. El valor está en las specs de `skills/`.
